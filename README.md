# UI-автотесты «Центр Социального обслуживания»

Автоматизированные UI-тесты дипломного проекта.

Тестируется фронтенд-приложение на **Vue.js + Element Plus**, работающее локально на `http://localhost:5173`.

Проект демонстрирует применение современных подходов к автоматизации UI-тестирования: **Page Object Model, Fluent Interface, Allure и AssertJ**.

## Технологический стек

| Технология | Версия |
| ---------- | -----: |
| Java       |     21 |
| Maven      |      — |
| Selenide   | 7.16.2 |
| JUnit 5    | 5.11.0 |
| Allure     | 2.29.0 |
| AssertJ    | 3.26.3 |

## Структура проекта

```text
src/test/java/
├── config/
│   └── TestConfig.java          # Базовая конфигурация Selenide
├── pages/
│   ├── HomePage.java
│   ├── LoginPage.java
│   ├── RegisterPage.java
│   ├── MenuPage.java
│   └── ProfilePage.java
└── tests/
    ├── HomePageTest.java
    ├── LoginPageTest.java
    ├── RegisterPageTest.java
    └── MenuPageTest.java
```

## Что покрыто тестами

* **Главная страница**

  * отображение для неавторизованного пользователя
  * переходы между страницами

* **Авторизация**

  * успешный вход
  * валидация пустых полей
  * проверка неверных учётных данных

* **Регистрация**

  * заполнение формы
  * валидация полей
  * успешная регистрация

* **Боковое меню**

  * проверка пунктов меню
  * проверка доступности пунктов для разных ролей: `USER`, `ADMIN`, `WORKER`

## Особенности

* **Page Object Model (POM)** — разделение логики тестов и взаимодействия со страницами
* **Fluent Interface** — цепочки методов для удобного написания тестов
* **Allure** — отчёты, шаги тестов и скриншоты
* **AssertJ** — удобные и читаемые проверки
* **Selenide** — лаконичное взаимодействие с UI и автоматическое ожидание элементов

## Конфигурация

Основные настройки находятся в классе `config.TestConfig`.

| Параметр        | Значение                   |
| --------------- | -------------------------- |
| **Браузер**     | Edge                       |
| **Headless**    | `false` *(можно включить)* |
| **Timeout**     | 10 секунд                  |
| **Base URL**    | `http://localhost:5173`    |
| **Размер окна** | `1920x1080`                |

## Запуск

### Предварительные требования

Перед запуском тестов необходимо установить:

* JDK 21
* Maven
* запущенное фронтенд-приложение на порту `5173`

Например:

```bash
npm run dev
```

### Запуск тестов

```bash
mvn clean test
```

## Allure-отчёт

После выполнения тестов можно открыть Allure-отчёт:

```bash
mvn allure:serve
```

Команда автоматически сгенерирует и откроет отчёт в браузере.
